# ლიტერატურის ტესტი (საიტი)

ამ საქაღალდის ფაილები იტვირთება **დახურულ (Private)** GitHub რეპოზიტორიაში, საიტს კი Netlify აქვეყნებს.
`Code.gs` (სწორი პასუხები, მოსწავლეების სია, საიდუმლო სიტყვა) აქ **არ არის** და არც უნდა იყოს — ის მხოლოდ Google Apps Script-შია.

ფაილები: `index.html` (აპლიკაცია, კითხვები, ტექსტები), `config.js` (Apps Script-ის /exec ბმული),
`manifest.webmanifest` + `sw.js` + `icons/` (ტელეფონში აპლიკაციად დაყენება), `netlify.toml` (Netlify-ის პარამეტრები).

განახლებისას GitHub-ზე ჩვეულებრივ მხოლოდ `index.html` იცვლება; Netlify ცვლილებას 1–2 წუთში თავად აქვეყნებს.
